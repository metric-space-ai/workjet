# Jour fixe speech adapters

`NativeJourFixeRoom.speechProvider` reserves one provider boundary for both `ctox-gateway` and `local-helper`. The same room microphone, partial transcript, slide player and errors are used for either implementation. No adapter is enabled by this change, and there is no automatic fallback. Models owns the adapters and their measured acceptance; the macOS fallback decision is Saturday 10 October at 20:00 Berlin.

Each selected adapter receives an immutable instance/project/meeting/deck scope and cancellation signal. `startListening` owns capture, stream transport and permission handling. `stop` is idempotent: a normal stop finishes the current utterance; an aborted signal cancels it without publishing a late result. Partial text is transient. `onCommitted` is only emitted after the final transcript has a verified CTOX meeting receipt; it refreshes the authoritative snapshot, never appends guessed text or producer IDs in the browser.

`prepareNarration` resolves the selected slide's authorized narration as an audio Blob (at most 32 MiB), rather than exposing a local path or HTTP business-data fallback. A gateway adapter uses the existing authorized audio channel. A desktop-only signed helper may use SpeechTranscriber for STT and AVSpeechSynthesizer for TTS, delivering its audio output through protected desktop IPC. It must request permission only after the microphone click, validate scope and helper identity, honor cancellation, and use the same final-receipt binding. Browser/React Native clients must not attempt to spawn the macOS helper. The separate React Native host still needs its native adapter.

The room cancels capture and narration on provider, instance, project, meeting, deck or meeting-state changes and unmount. Slide changes cancel stale narration and revoke its Blob URL. Late starts are stopped, old partials/receipts ignored and no late narration URL is created. Capture failures and permission denials are visible; they never silently select another provider or assert a recognized speaker. Narration remains ordinary player-controlled audio, not automatically played on arrival.

The adapter injection is a preparation hook, not evidence of installed speech availability, helper signing, native receipt support or Monday's end-to-end meeting acceptance. Those remain required on the installed stack.
