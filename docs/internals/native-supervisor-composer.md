# Native project supervisor composer

A persisted `team.role = supervisor` selects the native composer. The ordinary Code-provider start action is unavailable for that thread, including alternate send entry points. Other chat roles keep their existing composer.

The selected presentation instance, confirmed native project projection and persisted Code-project registration/working-copy proof must agree. The native thread identity is the existing Supervisor UUID, never a title or provider session. Missing/stale registry or a foreign persisted journal disables sending rather than falling back to local execution.

Before bind/submit, the composer waits for `threadEnvironment.setWorkjetConfig` to acknowledge `ctoxSupervisorTurn`. Unrelated configuration fields remain intact. Reopening resumes an unconfirmed intent with the same command ID and payload; a confirmed turn only watches its canonical execution command. Observations stop on unmount, terminal receipt or connection error. Refresh retries the saved request, and cancellation is shown as requested until the native state confirms it.

The receipt shows the submitted goal, native status, task ID, attempt, result and any native error. It does not invent a provider run ID or an event transcript. CTOX manages execution selection; the local Code model/harness picker is not displayed as if it controlled that native execution. Native model/harness selection and native event-page backfill remain separate acceptance work.

Web and Electron share this component and the existing guest control port. A host without that port fails explicitly; the React Native composer has not been integrated by this change. Installed Quit/Reopen, lost-reply recovery and end-to-end worker execution must be measured on the isolated acceptance stack; unit checks alone do not establish goals 8/9/A0.

Visual design: a quiet chat input with one send action, compact native status and expandable technical details. Pending/results have a bounded scroll area; no project team dashboard or duplicated computer/model controls.
