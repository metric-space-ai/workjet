# Native Supervisor message-text consumer

The execution-page contract mirrors CTOX's workjet-supervisor-execution-v1 fixture. include_native_message_text:true requests persisted worker.native_message_text events through the existing Owner-authorized guest/WebRTC watch. The decoder preserves execution_key, model_operation_id, native_message_id, model and upstream_request_id as native identities. It never substitutes SDK turn/item IDs. Text is bounded to 4096 Unicode characters per event and offsets to 65536 per message. A native chunk requires its exact event kind, an actual attempt and explicit native_message_text_supported:true.

readWorkjetSupervisorPublicExecutionPage opts into both native message and existing public assistant text by default. Requests with explicit page options retain those options. nextWorkjetSupervisorExecutionPageRequest preserves the actual attempt, cursor and independently advertised opt-ins. Older readers may reject an added opt-in: at most two further authorized guest reads remove only the unsupported flags, using the same original command, task, attempt and cursor. Authorization failures are not retried. Legacy task history remains visibly unsupported for live text; it is not a substitute model reply. There is no HTTP data path or new submit.

The presenter consumes reconstructSupervisorReplies(attemptId, events) from apps/web/src/supervisorPublicReplies.ts. Its exported SupervisorReply union includes existing SupervisorPublicReply and SupervisorNativeMessageReply. Native replies retain source:"native-message", executionKey, modelOperationId, nativeMessageId, model and upstreamRequestId; they have no provider turnId/itemId. Both variants carry text, phase, completed, truncated and incomplete for rendering. Replies preserve retained event order, exact duplicate backfill, contiguous Unicode offsets and actual native metadata. Gaps, changed witnesses and conflicting retained events keep the last prefix and mark it incomplete.

Native completed means only upstream message_stop. The projection never changes the saved task's terminal/status/attempt, closes the SDK query or marks a goal complete. Main owns wiring the exported projection and text opt-ins into the installed Supervisor presenter and measuring a new ordinary turn, streamed screenshot, follow-up and Quit/Reopen. This reader/projection change alone is not installed B3/B6 acceptance.
