# Private native Supervisor SDK model broker

The Node service can acquire NativeSupervisorModelBroker in its own scope after retaining the original native Source process and claim. It binds one offer/controller pair, keeps an ephemeral loopback credential in memory, and serves only the SDK Messages and CountTokens POST endpoints on an actual 127.0.0.1 ephemeral port. This HTTP surface is solely the LLM API consumed by the owned SDK; Business OS commands, data, tools and authority still use the private native IPC/WebRTC path.

The caller's session getter must come from the actual SDK init observer. Missing or replaced sessions cannot dispatch or receive another session's response. Correlation fields are not execution permission. Native resolves the original controller/account/model; the broker never exports OAuth, account keys, capabilities, root paths or enrollment tokens.

Each SDK request keeps its exact raw JSON and one randomly allocated operation UUID. It invokes once, reads from sequence zero, re-reads pending frames, and acknowledges only the next sequence after forwarding the current actual bytes. Native HTTP status and streaming mode remain intact; the broker does not infer the response model or author. Its limits match merged CTOX #564: 96 KiB requests, 32 KiB chunks, 8 MiB responses, 64 operations per retained controller and a 300-second deadline. Two local requests can be active.

A post-dispatch transport/protocol failure retires the broker and prevents subsequent automatic SDK retries from dispatching another model operation. The original unresolved IDs are returned at local shutdown for native reconciliation. Local HTTP drain is neither native cancellation nor a genuine SDK process/query/event drain witness. Native failed success-status responses end by closing the connection; actual upstream error responses preserve their status/body.

This additive resource is not yet activated on the Supervisor default path. The real service producer must connect the owned SDK init/session/turn/result and child-close/query-drain hooks, retain the same native mapping/process/controller, use its guarded worker tool bridge, and let native accept the joined observations. No actual SDK/model or installed Molecularity/B3/B6 pass is claimed. Tests use explicitly isolated protocol fixtures and real local HTTP streaming, not provider accounts.
