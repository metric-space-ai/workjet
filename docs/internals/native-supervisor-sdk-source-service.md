# Selected Supervisor SDK Source service

openSelectedNativeSupervisorSdkSourceService resolves the protected original Source enrollment against the current registered connection/computer, starts the selected native Source, and retains its actual startup identity. The owning Node service scope owns this child and the SDK holder; it must outlive client windows. The installed managed-runtime locator supplies the protected native executable/root. On first start it passes managedRuntime to this private function: prepare validates the current registered connection/computer and runtime before any spawn; retainStarted persists the actual original native identity before any SDK turn. Omitting managedRuntime resolves the saved mapping on restart. A conflicting runtime or changed native identity fails closed; there is no enrollment-seeding child, settings/RPC execution switch or startup-DTO authority.

runNext reads and claims one actual native offer through that same Source object. It joins the offer ID, execution key and deadline, accepts only the supported claude-code route and fixed native worker_dispatch contract, and invokes the genuine pinned Claude Agent SDK query. Claim ambiguity is not retried: attempted offers remain retired until their original deadline; expired offers cannot be claimed again. No replacement controller, account, grant, model or fallback is created.

A qualified protected runtime producer may opt in with includeConfirmedGoalRead:true. Only then does the original claim send include_confirmed_goal_read:true and require exactly one worker_dispatch and one confirmed_goal_read descriptor. The default claim omits the added field for compatibility with older native versions. Unknown, duplicate, missing or unsolicited tools fail before SDK startup, without retrying that claim. The fixed confirmed_goal_read operation sends tool_arguments_json:"{}" through the same offer/controller and reads the Owner-confirmed definition and actual saved Core step progress. A null confirmed_goal is preserved; partial results do not become completed status. There is no caller-selected actor, project, root, lease, confirmation or schedule.

The child has a private 0700 home/config/tmp directory, a complete replacement environment enforced at its actual spawn callback even if the SDK merges ambient variables, no inherited account secrets, no settings sources, no additional host directories, no session resume and no built-in SDK tools. It uses the retained SDK-only model broker and an in-process native MCP tool server. The shared Supervisor role extension is the system prompt; the original native assignment is the user input. Unsupported operations are reported explicitly.

Every actual SDK PreToolUse callback is checked against the observed parent SDK session. Only mcp__workjet_native__worker_dispatch and the admitted mcp__workjet_native__confirmed_goal_read are supported; built-ins, foreign MCP calls and subagents are denied. Runtime-generated correlation is injected after the actual hook. Model-selected nonces and arbitrary MCP metadata cannot register calls. The handler removes private correlation, preserves one immutable operation UUID and fixed tool name per actual SDK tool call and uses the original native tool_call channel. Duplicate handler entry shares the same request/result. Correlation cannot be reused across tools. Ambiguous replies or protocol mismatches retire the bridge without another operation. Native remains authoritative for the original peer/lease/project/role/physical consumer and persisted worker intent.

One original query is bounded by its native deadline (at most five minutes), 32 SDK tool turns and the existing broker/journal budgets. The holder captures actual SDK ChildProcess objects, records init/parent/result metadata through the original Source journal, joins the real iterator and successful query.close callback, stops only its own captured children, and awaits child stdio close, journal sink and model/tool drains. UI disconnects are not prompt EOF or service cancellation. Service-scope close aborts and joins the retained query before the native transport finalizer. Caller cancellation cannot clear a still-running query's custody.

The local return contains only original correlation and local drain observations with executionReady:false. It does not submit SDK reply text, actual_json, an execution permit or a caller-made terminated result. CTOX owns native model/message/result joining, result assembly, durable continuation and offer/wait integration. There is no default project activation in this change: the production managed locator and native result path must invoke this private scoped seam.

Focused tests use mock SDK messages and isolated native protocol fixtures with actual owned Node children. They cover environment/tool isolation, fixed goal-reader admission, hook correlation, duplicate and ambiguous operations, original-claim replay prevention, owner cancellation, child/query/sink drain and missing/foreign results. They are not real-model or installed B3/B6/goal-8/9/G6 acceptance. Main retains the sole installed-app observation path.
