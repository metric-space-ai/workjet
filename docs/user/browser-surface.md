# Browser workspace

Enable **Web Stack Browser** in the chat's **Tools** menu to show Browser in the right panel. Opening the panel or enabling the tool does not create a browser session. Choose Browser when you want to open one.

When the tool is disabled, Browser is hidden from the panel launcher, add menu, tabs and mini-player. Browser shortcuts no longer open it. Other work surfaces remain available. Existing browser sessions are retained, so enabling the tool again restores their tabs; disabling the tool is not a command to delete their data.

New chats use their draft's tool selection. Once a chat exists, its own tool settings apply. A Browser entry may explain that the current app cannot display previews when the tool is enabled but the runtime does not support them.
