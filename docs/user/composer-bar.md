# The composer bar

Write in the full-width text field above the bar. **Enter** sends, **Shift+Enter** adds a line, and **Cmd+Enter** also sends.

The **+** adds images or project files. Choose a saved **Luma** to use its harness, model and computer, or choose **Manual** to select those three controls separately. The **gear** opens advanced settings, including context, system prompt, tools and reasoning. The round arrow sends the message.

Use the **microphone** to dictate into the text field through the speech backend configured in **Settings → Speech**. Press **Stop dictation** to finish and append the text; review it before sending. With no available speech backend, the button opens Speech settings. Permission or instance-support errors appear beside the microphone with a settings link.

Normal chats, Parents, Workers and project Supervisors keep the same bar at narrow widths. The Supervisor also shows **Task / Chat**. Its instance manages its Luma and model choices.
