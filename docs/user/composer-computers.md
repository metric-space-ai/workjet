# Choose and configure a computer for a chat

Open **Computer** in the composer to choose where a new chat runs. The same control is available in narrow windows. A computer without the selected project stays visible with an explanation, but cannot be selected.

Use the arrow beside a computer to open its details and settings. The list stays on the left when there is room; in a narrow window, use **Back to computers** to return to the list. Inspecting or saving computer settings does not select it or move the chat.

For a computer whose settings are available in the active instance, edit its label and harness configuration directly in the popup. **Save computer** waits for confirmation. If saving fails, your edits stay in the form so you can retry. **Cancel** discards the edits; going back or closing the popup retains them while you remain in the chat. Changes also survive switching between wide and narrow composer layouts. Saved computer settings apply to workers using that computer.

Connection type and current-project availability remain visible. Harness switches describe saved configuration. The host check can report when that configuration disagrees with installed tools; a failed check is shown separately. Being connected does not by itself grant access to another instance's computer settings.

Once a chat has started, the computer choices are locked with an explanation. Details and authorized settings remain available. **Add computer** opens the existing computer setup.
