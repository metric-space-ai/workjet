# Choose a computer for a chat

Open **Computer** in the composer to choose where a new chat runs. The same control is available in narrow windows. A computer without the selected project stays visible with an explanation, but cannot be selected.

Use the arrow beside a computer to open its details. The list stays on the left when there is room; in a narrow window, use **Back to computers** to return to the list. Inspecting a computer does not select it or move the chat.

Details show the connection type, whether the current project is available there, and the saved harness configuration. An enabled harness is a saved setting; it does not by itself confirm that the computer is connected or the tool is installed.

Once a chat has started, the computer choices are locked with an explanation. Details remain available. **Add computer** opens the existing computer setup.
