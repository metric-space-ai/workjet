# Choosing a model in Manual mode

Choose **Manual** in the worker selector, then open **Model**. The provider icons organize the gateway catalog; choosing an icon only changes the list you are browsing. Select a model to use it in the current chat. Harness and model are independent choices when your instance routes through the gateway.

Choose **Custom model ID…** to enter a model that is not listed. The popup expands beside the list when there is room. In a narrow window, the editor fills the popup and **Back to models** returns to the list.

Use **Use model** or press Enter in the editor to apply the ID. Leading and trailing whitespace is removed; an empty ID cannot be applied. **Discard** abandons the edit. Moving focus, returning to the list, or closing the popup keeps the edit without applying it. Reopen **Continue model edit…** to resume. An unfinished edit survives resizing the composer while the chat remains open.

The narrow composer offers the same Harness and Model controls directly. A missing catalog shows its availability message and still allows a custom model ID. Gateway availability, account access, and model support determine whether a selected model can run.
