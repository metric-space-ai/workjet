# Project cards and settings

A project card has a website preview or logo and three metrics. Values appear above their labels. A domain title opens its website; the arrow in the preview opens the project overview.

Open the card’s ⋯ menu and choose **Configure project** to manage its repository, website, description and weekly meeting. Goal, phase and status are available in a compact expandable section. **Cancel** discards edits. **Archive project** hides the project without deleting its history; archived projects can be restored.

KPI configuration uses one sentence for each metric. It becomes available when the connected CTOX instance supplies its KPI service. Until then, sentence fields are disabled and existing card values are retained. Available results show the computed value, source and calculation time. Missing sources and failed resolutions show an error instead of a guessed value; changing a sentence invalidates its previous result.
