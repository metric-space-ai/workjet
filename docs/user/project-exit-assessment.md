# Assess a project's five-year exit

On desktop and web, each project card shows **Essential KPI · Exit in 5 years** beside its existing KPIs. Select the
measure to open the assessment, or open the project overview for the full report.

The headline is expected sale proceeds for the whole equity in five years,
including the probability of failure or no sale. The report separately shows the
chance of a sale, the price if sold, the forecast range and its exit date. All
amounts are nominal EUR before transaction fees and personal taxes.

Start with **Resource plan**. Enter hours per week, monthly cash budget and
whether the project uses its own plan or the same resources as other projects.
Save the proposal to start assessment research through the project's supervisor.
These limits do not automatically confirm a monthly spending allocation, future
funding or ownership rights. Required evidence and plan gaps remain visible.

Use **Update assessment** to request a new assessment. **Research in progress**
shows an active research request. **Inputs needed** names the missing evidence;
it does not imply a zero valuation. A calculated **Provisional** result still
requires review of its assumptions and sources. V1 does not publish independently
reviewed assessments.

Expand the report to inspect scenario contributions, sources, assumptions,
resource limits, operating value and financing. Expired evidence labels the
result **Out of date**. Assessment history retains old results with their original
five-year horizons. A failed or incomplete current assessment does not reuse an
old amount as its current result.

When a previous calculated amount is available and greater than zero, the card
shows the percentage change. The report names that baseline's date. This compares
recorded assessments; automatic snapshots at each regular Jour fixe are a later
integration.

Projects need a connected, updated CTOX instance and a registered supervisor to
run research. This feature does not enable automatic monthly runs; the next due
date is visible so an update can be requested deliberately.
