# Project thread basics

Changing a chat's harness checks its model against the target harness's reported models and the gateway catalog after the catalog has loaded successfully. While loading, offline, or after a failed request, the current model stays selected and no fallback notice appears. If a successful check finds the model unavailable, the composer selects the target harness's checked default and explains the change below the composer.

Workers commissioned through the Supervisor's worker-dispatch tools receive their own worktree and use the existing single-PR submission and archival lifecycle. Chats opened manually remain ordinary chats. Existing worker conversations and conversations continued on another computer are never put through first-time worker preparation again. One-Shots remain leaves and cannot commission children.

Every harness and project role starts with Bypass permissions (Full access). Imports retain the project's execution-policy reference and use the same permission default, with or without a worktree. Existing project conversations switch to this default once during upgrade. The thread's permission selector remains available for later explicit changes.

Unattended Persistent and One-Shot Workers send questions, choices and approvals to their project's Supervisor. The Worker shows Waiting for Supervisor; only Supervisor escalations appear under Needs you. The Supervisor's answer resumes the original Worker request. If you personally write in a Worker conversation, that conversation may ask you directly.

Persistent Workers use their own mini-kanban and goal tools when the harness supports them. Otherwise Workjet retains the completed turn's reported result server-side without treating it as verified goal completion. Missing tools never become a prerequisite for continuing.

If the desktop cannot read its saved connections, worker access can still use the local service with the matching environment identity. Workjet shows one informational notice per desktop process and preserves the saved catalog. A local-service authorization failure is still reported normally.
