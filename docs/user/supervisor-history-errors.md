# Supervisor history errors

If execution history cannot load, Workjet distinguishes an instance whose owner session or supervisor controls are not ready, an invalid response, and a receipt for a different request or run. Reconnect for a readiness failure; check the instance version for an incompatible response.

A history error does not submit another supervisor request or restart a completed task. Refresh reads the retained run. Private exception text and credentials are never included in the displayed error.
