# Supervisor messages

Write to the project's Supervisor in its chat. Replies support Markdown, including bold text and lists.

**Enter** sends; **Shift+Enter** adds a line; **Cmd+Enter** also sends. **Task / Chat** is in the bar beneath the text field. The Supervisor's Luma and model controls show the project's instance route; their tooltips explain when the instance manages those choices.

When a previous request is still running, you can keep drafting. Choose **Continue anyway** to send a separate message. The previous task remains in **Task history**, where you can select it to read its answer, refresh its status, or request cancellation.

If CTOX has not yet acknowledged a submission, wait for its receipt or use **Refresh task**. Workjet preserves that request through quit and reopen so it can recover the same submission safely.

Live replies depend on the connected CTOX instance. When live text is unavailable, the chat states that explicitly and still displays the saved task answer when it arrives.
