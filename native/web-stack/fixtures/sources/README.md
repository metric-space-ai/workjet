# Synthetic source fixtures

Every fixture in this directory is an original, hand-authored Workjet test artifact.
All names, addresses, people, and identifiers are intentionally fictional. Reserved
`.example` and `.invalid` domains are used for contact data. Format-shaped source
identifiers are explicitly marked synthetic in fixture metadata or comments.

These files are minimal parser inputs written from scratch. They are not captured,
redacted, transformed, minified, or excerpted upstream website or API responses.
